# Bilder, Sounds und Stimmen für den Fernseher

Einfach die Dateien mit **genau diesen Namen** in die passenden Ordner legen und die TV-Seite neu laden.
Fehlt eine Datei, läuft das Spiel trotzdem – es bleibt dann an der Stelle nur still bzw. zeigt den Standard-Look.

## Bilder (`img/`)

| Datei | Wofür | Tipp für ChatGPT |
| --- | --- | --- |
| `img/logo.png` | Logo oben links im Spiel (transparenter Hintergrund, ca. 400×160) | „Logo-Schriftzug PROJECT HAVOC im Piratenstil, Gold und Totenkopf, transparenter Hintergrund“ |
| `img/table.jpg` | Hintergrund hinter dem Spieltisch (1920×1080) | „Dunkles Deck eines verfluchten Piratenschiffs bei Mondlicht, Nebel, Blick von oben, viel ruhige Fläche in der Mitte“ |

## Soundeffekte (`sfx/`, MP3)

| Datei | Wann |
| --- | --- |
| `sfx/shuffle.mp3` | Spielstart, Karten mischen |
| `sfx/card-play.mp3` | Karte wird gelegt |
| `sfx/card-draw.mp3` | Karte wird gezogen |
| `sfx/penalty.mp3` | Strafkarten (+2, +4, Würfel) |
| `sfx/shield.mp3` | Rettungsring wehrt ab (z. B. Platschen) |
| `sfx/cannon.mp3` | Kanonenrückschlag |
| `sfx/swords.mp3` | Meuterei (Säbelklirren) |
| `sfx/whirlpool.mp3` | Strudel |
| `sfx/dice.mp3` | Würfelwurf |
| `sfx/ship-bell.mp3` | Ein Ereignis beginnt |
| `sfx/kraken.mp3` | Kraken-Angriff |
| `sfx/thunder.mp3` | Sturm |
| `sfx/coins.mp3` | Plünderung |
| `sfx/bottle.mp3` | Flaschenpost (Glas/Korken) |

Kostenlose Quellen: **Kenney.nl** (z. B. „Casino Audio“ für Karten und Würfel, CC0), **Pixabay Sound Effects**, **Mixkit**.
